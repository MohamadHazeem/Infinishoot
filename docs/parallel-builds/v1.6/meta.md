LANE: meta

Goal: reasons to come back, without breaking "every run starts equal" (no permanent stat upgrades).
1. Heat / run modifiers you choose before a run (Hades-style): a HEAT screen from the mode select with 8-10 toggles each worth heat points (enemies +25% speed, elites every 40 s, no healing pickups, bosses +1 phase attack, shop prices +50%, fewer chests, enemy bullets faster, one revive only...). Total heat multiplies score and end-of-run rewards (Bolts etc.), is shown on the HUD and in run history; best heat cleared per mode is saved. Works in co-op (host's heat applies, shown to clients).
2. Weekly challenge runs: a WEEKLY mode with a fixed seed per ISO week and a rotating weird rule set from a list (only explosives, giant enemies, one-hit hero, double speed, no left-click weapon, everything elite...), deterministic from the week number; its own local best score table, and post to the optional online leaderboard if it's configured (see src/net/leaderboard.ts; keep it optional).
3. Meta unlocks that are not power: cosmetics (skins/trails/pet hats/HUD themes), new starting loadouts and a CODEX with lore entries for enemies, bosses, biomes and heroes unlocked by encountering/defeating them (extends the bestiary screen). Unlock conditions tied to achievements/heat/weekly. Save format migrates cleanly (src/game/save.ts) — old saves must load.
Owns: src/data/modes.ts, new src/data/heat.ts, src/data/weekly.ts, src/data/codex.ts, src/game/save.ts (additive), run flow hooks (systems/runFlow.ts, small), screens for these (add new screens in a new file src/ui/metaScreens.ts and only small hooks in src/ui/screens.ts), tests/meta.test.ts.
