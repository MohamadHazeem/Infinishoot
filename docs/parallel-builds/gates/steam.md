# Lane steam: Steam-ready desktop build (no account needed yet)

Goal: the day the owner creates the Steamworks app, shipping to Steam is one command. Nothing here needs a Steam account: use a placeholder App ID (480, Valve's test app "Spacewar", for local testing) read from config/env, never hard-coded elsewhere. Read electron/*, package.json build config, .github/workflows/release.yml, docs/RELEASING.md, src/data/achievements* / meta.ts and src/game/save.ts first.

Build:
1. Steam integration in the Electron app behind a flag: optional dependency `steamworks.js` (the maintained N-API binding) loaded only when the app runs with STEAM_APP_ID set or a `steam_appid.txt` next to the exe; the web build and the non-Steam desktop builds must not load or bundle it. If Steam isn't running, the game runs normally.
2. Achievements: map every existing in-game achievement id to a Steam achievement API name (generated table, scripts/steam/achievements.mjs producing a CSV/VDF the owner can import in Steamworks, plus the 64x64/256x256 icon PNGs rendered from the existing pixel icons); unlocking in game also unlocks on Steam; on start, sync the save's already-earned achievements.
3. Rich presence ("Stage 3 · Sunset Dunes · Ronin"), Steam overlay friendly (no input lock), Steam friends "Join game" via rich presence connect strings that carry the existing invite code (the game's PeerJS invite link flow stays the transport).
4. Steam Cloud: save file location suitable for Steam Auto-Cloud (document the exact root/path patterns for Windows and macOS in docs/STEAM.md).
5. Build: `npm run dist:steam` produces unpacked Windows x64 and macOS (universal or arm64+x64) app folders for SteamPipe (no installer, no auto-updater, no "new version" notice in Steam builds). scripts/steam/app_build_*.vdf and depot_build_*.vdf templates with placeholders, and `npm run steam:upload` that runs steamcmd with those files only when STEAM_USERNAME and an app id are set (it must refuse otherwise). Do not run steamcmd.
6. Steam Deck: controller-first check (the game already supports gamepads): default to gamepad prompts when running on Steam Deck (SteamDeck env / screen 1280x800), make sure 1280x800 menus fit (screenshot `--size 1280x800` if you can run a browser; otherwise list it as a check for the lead), and text is readable at that size.
7. Store page kit in marketing/steam/: short and long descriptions (EN and AR), feature bullets, tags list, system requirements, the capsule/screenshot size list Steam requires with which in-game scenes to capture for each, and a trailer shot list (90 s). No generated art in this lane.
8. docs/STEAM.md: what the owner must do in Steamworks (create app, pay the fee, set App ID, import achievements, configure cloud paths, depots, branches), then the one-command flow.
9. Tests: tests/steam.test.ts for the achievement mapping (every achievement mapped, names valid, stable), the rich presence string builder, and the flag logic (Steam code never loads without the flag).

Owns: electron/**, scripts/steam/**, marketing/steam/**, docs/STEAM.md, the build section and scripts in package.json (add the optional dependency there; keep the lockfile consistent with `npm install`), tests/steam.test.ts, notes/lanes/steam.md. Small additive edits: a platform hook to forward achievement unlocks (where achievements are granted) and rich presence (stage/hero changes) through one small module src/platform/steam.ts.
