# Gate 10 trailer capture and press kit

The [press kit](../../docs/PRESSKIT.md) has the fact sheet, controls, credits, screenshot captions and a 20-take cut sheet. The [press gallery](../../marketing/screens/) contains 30 English 1920 × 1080 PNGs copied directly from the selected frames. The editor's [picture masters](../../shots/g10-trailer/frames/) are **20 numbered PNG sequences, 5,400 frames, 90 seconds at 60 fps**, about 2.1 GiB. Copy that directory before removing the worktree. Git ignores it. The rig can regenerate it from the source manifest.

## Recording decisions

- The first five seconds start inside the Bright Meadow swarm. King Bopper introduces the bosses, then a drone escort and a parry establish the twin-stick controls. The Flare Buster salute leads into Storm Drones, Ronin in Neon City, the factory and Sky Fortress. The latter half covers couch co-op, a team ultimate, three more bosses, Magma Isle, the golden portal and a photo-mode postcard. The last four seconds carry the game's own logo. All 20 test links, seeds, in-points, press selects and track choices are in [shots.mjs](../../scripts/capture/shots.mjs). Run `node scripts/capture/capture.mjs --list` for the full URLs' query strings.
- A private Chromium context per take loads the production preview at 1920 × 1080, device scale 1, locale en-US and UTC. The fixture fixes the calendar, seeds the cosmetic random stream, drives game-loop RAFs and delayed cues in 1/60 s ticks, and seeks DOM animations in picture time. Every output frame goes through the ordinary game renderer. Custom tracks use the shipping CinematicCamera with an independent camera for the final draw. The normal input camera continues to aim the hero. Boss introductions, evolution, knockout and the photo postcard use the game's own camera choreography. PNG sequences preserve the game's native pixel scaling.
- The two co-op segments are staged offline. Take 11 runs the shared-screen input path with three heroes. Take 12 uses the four-hero teammate fixture and its real team-ultimate effect. The press kit labels the setups. No public broker, player names or external accounts were needed.
- For the ordinary gameplay HUD, use the dune escort and couch crew. The other takes suppress incidental HUD panels while preserving meaningful cinematic captions. The factory retake frames Boxer Jack in combat so that his wind-up, the hero and the ground warnings stay together. The press select is frame 210. The photo moves around a paused, saluting hero.
- Master filenames run from `00000.png` through `00239.png`, `00299.png` or `00359.png` in each shot directory. Import at 60 fps. PNGs carry no audio. The lead owns the edit, music, sound mix and delivery encode. Desktop package metadata supplies the developer credit. This kit makes no release-date, price or Steam certification claim.

## Balance and runtime verification

The pre-capture skillbot cohort used the mortal Rookie, Normal, no pet, season off, seeds 1 and 2, and the stock 2,100-second cap. Both cleared every stage in 1,036.93 and 1,021.00 game seconds. This two-seed paired check can detect a change in those runs. It has insufficient precision to certify Gate 2's 40–60% population target. The [previous twenty-seed cohort](g8-roles.md#skilled-bot-results) reported 15/20 on its revision.

The pre-capture HIGH 1080p heavy fixture on the Apple M5 Pro Metal adapter measured 60.00 fps, frame interval p95 16.7 ms, main callback p95 4.6 ms and GPU p95 4.49 ms. The shell Chromium launcher aborted before a page existed. The reference views, editor takes and GPU measurements used managed headless Chromium with a local production Vite preview.

The post-capture run of `npm run skillbot -- --runs 2 --seed 1` also cleared 2/2 in 1,036.93 and 1,021.00 seconds (mean 1,029.0). [Before results](../../shots/g10-trailer/skillbot-before.json) / [after results](../../shots/g10-trailer/skillbot-after.json).

The **Metal performance gate passed**. The stock collectors measured all 60 gameplay rows, both thousand-light renderer rows and all four cold loads. Three 1280 × 720 LOW 4× CPU rows missed the initial budget (heavy, double and team). All three passed their single retry. The same HIGH 1080p heavy comparison after capture measured 60.00 fps, frame interval p95 **16.8 ms** versus **16.7 ms** before, callback p95 **5.4 ms** versus **4.6 ms**, and GPU p95 **2.26 ms** versus **4.49 ms**. The final sample had 260 median enemies and 499 median projectiles. `npm run bench:real -- --check --from-report shots/g10-trailer/metal.json` passed the repository's unmodified budget. [First matrix](../../shots/g10-trailer/metal-first.json) / [matrix with the three retried rows](../../shots/g10-trailer/metal.json).

## Release checks and remaining issue

- `npm test` passed all 157 unit files on the final full run (`TEST_JOBS=4`). The first full run failed host migration while the shared machine was heavily loaded. It then passed in isolation and in the final complete suite. [Full test log](../../shots/g10-trailer/unit-final.log)
- `npm run typecheck` and `npx vite build` passed. `npm run smoke` passed all modes, including the mortal game-over path.
- The frame and press verifiers passed. FFmpeg decoded every frame in each of the 20 sequences at 60 fps with error-on-decode enabled. Every published still is a byte-for-byte copy of its named master frame. The [press contact sheet](../../shots/g10-trailer/press-contact-sheet.jpg) includes all 30. I inspected all twelve EN/AR visual pairs above. The unmodified meadow QA link reaches the level-up screen within its six-second wait.
- Offline co-op has one outstanding full-harness failure. Shell Chromium is blocked by macOS Mach bootstrap permissions. The stock two-page test ran in managed headless Chromium over its real local WebRTC channel and in-process signalling. Its client-ping portrait assertion failed on the first attempt and retry. A diagnostic run with the default graphics settings and the harness's watcher-disabled Vite server reproduced it. At the attempted ping, the host had `mode=levelup` and the wait screen, and the client was choosing a level-up. The host accepts that message only in combat mode. The `--only "client pings" --secs 52` run passed with both machines in combat. All other full-run assertions passed, including objectives across three stages, revive, reconnect, restart, lobby return and kick. The diagnostic run sent 1,869 snapshots, mean 1,769 bytes and max 13,249. This lane owns neither the co-op harness nor gameplay. A supplemental run of the entire scenario list waited for both peers to return to combat before sending the ping and passed every assertion (1,920 snapshots, maximum 14,691 bytes). The stock harness still has the timing failure across the boss reward and level-up.
- Final video editing, soundtrack and release encoding belong to the lead. This lane ships the source picture and press assets.
