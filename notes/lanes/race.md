# Lane: race (competitive extras)

## What players get
- **RACE** (PLAY ONLINE > host > GAME: RACE, 2-8 players). Everyone plays the same seeded stage at the same time, each in their own world (a plain solo run, like PvP's stage: starting shop, level-ups, the stage boss). A **rival board** on the right of the HUD lists every racer, sorted live: place, name, a progress bar (left half = the stage timer, right half = the boss's lost life, with a tick at the boss) and a label (`STAGE 63%`, `BOSS 40% LEFT`, `FINISHED 4:12`, `K.O. · STAGE 40%`, `LEFT`), plus the race clock (`4:28 LEFT`, blinking under a minute). **First to beat the stage boss wins.** If the race clock (7:00, menus included, the same for everyone) runs out, or nobody is still racing, the furthest racer wins (finishers by time, then progress, then standing over knocked out, then who lasted longer). K.O.'d racers get a live WAITING FOR THE RACE board. RACE RESULTS on every screen: places, labels, levels, rank badges and your rating change. Audio: `vo_race_go` when the first fight starts, `vo_final_round` with one minute left, `vo_victory` + `victory_fanfare` for the winner, `defeat_sting` for everyone else. Heat is off in races. Nothing is banked (like PvP).
- **CHALLENGE A FRIEND** (works offline). A finished solo Standard / Endless / Boss Rush run without heat shows **CHALLENGE A FRIEND** on the game over screen: it copies a short code like `IS1.1hk7x.sn.ace.scatter.grenade.storm.13ff.3.Lina.0c2k` (seed, mode, difficulty, hero, loadout, score, stage, name, checksum). EXTRAS > COMPETE > CHALLENGE A FRIEND: paste it, READ CODE shows who scored what with which kit, ACCEPT CHALLENGE plays the same seed, mode, difficulty, hero and loadout (locked items too: it's their kit) with a **score-to-beat chip** on the HUD (their score, yours with a bar). Passing it plays a banner (NEW LEADER!) and a fanfare; game over says `YOU BEAT LINA BY 1,234! SEND THEM YOUR CODE.` or how far behind you are, and offers your own code to send back. The last code is kept (COPY under YOUR LAST CODE).
- **LOCAL TOURNAMENT** (EXTRAS > COMPETE > TOURNAMENT): 4-8 names in seed order, a bracket (byes go to the top seeds), quarter-finals / semi-finals / final, and a CHAMPION panel with a pixel trophy, the `trophy` sample and `vo_victory`. Two kinds:
  - **RACE ON THIS PC** (hot seat): each match has its own seed; both players play it in turn (Medium, the PC's current loadout). Each turn is one race stage on its own: beat the boss, or get furthest before the 7:00 clock. Further wins, then faster, then score, then the higher seed. `vo_round_fight` / `vo_final_round` start each turn. The bracket stays across restarts (`infinishoot.tourney.v1`).
  - **ONLINE MATCHES**: play each match as an online PVP or RACE lobby; when it ends with a single winner and both match players are in it (by name, case-insensitive), the result is recorded automatically. Otherwise press `<NAME> WON`.
- **RANKED** (local rating). Online RACE and PVP results change an Elo-style rating stored in the save. Every opponent is a pairwise game (win / loss / draw by place) with K split across them, so a 6-player race moves about as much as a duel; the first 10 games of a season use K 40, then 24. Seasons are calendar months: the first rated match of a new month archives the old one (EXTRAS > COMPETE > RANKED > PAST SEASONS) and moves the rating halfway back to 1000. **Rank badges** (Bronze B, Silver S, Gold G, Platinum P, Diamond D, Legend ★) on lobby cards, race results and the RANKED page (big badge, progress to the next tier, games / wins / peak, tier list). A shared **online ladder** (top 50 per season) appears only when the build has `VITE_LEADERBOARD_URL`.

## Knobs
- `raceTuning` (src/game/raceRules.ts): `limit` 420 s race clock, `report` 0.5 s (client progress and host board rate), `finalCue` 60 s.
- `rankedTuning` (src/data/ranked.ts): start 1000, K 40 for the first 10 games then 24, season carry 0.5, floor 100, ceiling 4000, 24 seasons kept. Tiers (`RANK_TIERS`): Bronze 0, Silver 1100, Gold 1250, Platinum 1400, Diamond 1550, Legend 1750.
- Tournament: 4-8 players (`TOURNEY_MIN` / `TOURNEY_MAX`), brackets of 4 or 8.

## How it works
- Pure rules: src/game/raceRules.ts (progress, standings, labels, wire-row cleaning, challenge codes, brackets, hot-seat turns, auto-record, stored-bracket cleaning) and src/data/ranked.ts (tiers, Elo, seasons, migration, badge markup). Game side: src/game/systems/race.ts. UI: src/ui/raceUi.ts (rival board / challenge chip on the HUD, RACE RESULTS `raceres`, COMPETE `compete`, TOURNAMENT `tourney`, lobby badges, game over button), CSS injected from there.
- `game.race` (`RaceRun`): net (`host` / `client` / `local`), rows in lobby order, `you`, race clock, phase. `raceBegin` sets `role` 'solo' (connection kept), stops effect recording, turns heat off for `startRun({seed, difficulty})`, then shows the RACE! banner. `raceTick` (every update, any role) updates this machine's row from its run: progress from `director.time / duration`, then the boss's life; finished when the stage moves on (`mode` cleared / portal / transition / shop after the boss, or `stage > 1`); K.O. when `mode` is dead.
- Messages (menu-time, not snapshot fields): host -> client `rcgo {seed, difficulty, names, ranks, you, limit}`, `rcb {rows, clock}` (board, every 0.5 s), `rcend {rows}`; client -> host `rcp {row}` (its own row; the host keeps names/colours, timestamps finishes with its own clock and never lets a finish be undone). Lobby ranks: client -> host `rkme {r}` once per connection, host -> all `rkl {l: [{n, r}]}` after every lobby refresh.
- Hooks are chained onto Game's method fields at install (so netHost/netClient/runFlow/online stay untouched): `endRun` (K.O. / quit in a race: wait, or end a hot-seat turn), `leaveToTitle` (drop race, challenge, turn, ranks; back to 4 players), `startRun` (a new run drops the challenge), `hostStart` (RACE starts a race; other kinds refuse more than 4 players), `refreshLobby` (8-player cap for RACE, `rkl`), `onHostMessage` / `onClientMessage` (race and rank messages), `onClientLeft` (a racer who leaves is LEFT), `pvpOver` (rating and tournament auto-record), `bankAndShow` (challenge code), `screens.onShow` / `onLobby` (game over button, badges).
- `NetHost.setMax(n)` (src/net/peer.ts): RACE lobbies take 7 guests.
- Save v7 adds `ranked` (`normalizeRanked` migrates older saves to a fresh 1000 rating; the ladder id is made on the first ladder post).
- Online ladder: src/net/rankedBoard.ts (client), server/leaderboard/ranked.js (route, listed in routes.js): `GET /ranked?season=YYYY-MM` top 50, `POST /ranked {id, season, name, rating, games, wins}` keeps the latest per save id, plausibility (rating 100-4000, wins <= games, |rating - 1000| <= 40 x games + 500) and one post per 20 s per IP. The lobby browser route accepts `race` lobbies of up to 8.

## Unfinished / risky
- No real two-machine race (the PeerJS broker isn't reachable from the build machine); 8-player lobbies were only tested with fake peers. The host relays the board twice a second: 8 racers is about 8 x 2 small JSON messages a second, far below a co-op snapshot.
- Ratings are self-reported (each machine computes its own from the rows it saw) and the online ladder is for fun, not proof. Names identify players for PvP ratings and tournament auto-record, so two players with the same name confuse them.
- Race fairness: the race clock includes menus (level-ups, shop, pause) on purpose, so pausing doesn't help. Everyone gets the same seed, but enemy spawns still depend on how each player plays (positions, kills), as in PvP's stage.
- Challenge codes trust the sender's score (they're a friendly target, not a leaderboard). Runs with heat, daily, weekly, gauntlet, races, versus and local co-op don't make codes. The halloween season follows the date, so a code played in another season can differ slightly.
- Hot-seat turns use the PC's current loadout for every player (pick yours in LOADOUT before your turn); difficulty is fixed at Medium.
- i18n: new copy is English through `localize` / `localizeHtml` (falls back to English); no Arabic catalog entries were added for the lane's strings.

## Decision-log paragraph for PLAN.md
- 2026-10-20: Race lane (notes/lanes/race.md). RACE is a fifth online game type (2-8 players: `NetHost.setMax`): every machine plays the same seeded stage as a solo run over the open connection (PvP's stage model), clients report progress twice a second and the host shares a live rival board (stage timer, then boss life) and ends the race when someone beats the boss, nobody is left or a 7:00 race clock runs out (furthest wins). CHALLENGE A FRIEND turns a finished solo run into a ~60-character checksummed code (seed, mode, difficulty, hero, loadout, score, stage, name); playing it uses that exact setup, locked items included, with no heat and the score to beat on the HUD. A local TOURNAMENT bracket (4-8 names, byes to top seeds) plays hot-seat race turns per match seed or records online PvP/race results automatically by name. RANKED is a local Elo rating (pairwise per opponent, K split across them, 40 for 10 placement games then 24) with monthly seasons (half the gain or loss carries over), Bronze to Legend badges on lobby cards and results, and an optional season ladder route (`/ranked`). All hooks chain onto Game methods at install time, so the shared netcode files only gained the `race` kind; save v7 adds `ranked`.
