# Gate 10 · launch readiness

## Player paths

- **Collection → Patch Notes** opens two local release pages, with previous, next and back actions. The 3.0 entry is explicitly a preview. The shipped app version remains the lead's release decision. English and Arabic are authored. The other five catalogs use their established English fallback.
- **Steam Deck** uses the integrated controller's L1/R1/L2/R2 labels, a readable floor for small menu notes, and Steam's native text dialog for names and codes when available. Committing text fires the normal input/change handlers. Cancelling preserves the original field. The existing in-game keyboard covers clients without the native API. A controller can now keep the rolling capture and open Highlights from Pause. A non-Steam web session never initializes Steam.
- **Steam Workshop** supports both consumption and private draft creation with the pinned official steamworks.js 0.4.0. Use Settings → Mod Packs to browse, enable an installed subscription or upload a valid local pack. Restart to apply pack changes and reconcile subscriptions. The existing pack validator, ordering and co-op content hash still apply. In the Arena Editor, subscribed playable arenas open as editable copies. A saved copy can be played or hosted. The Share tab uploads a private draft. Steam's item page handles agreement and visibility.
- Native reads use the Steam-supplied install folder and two fixed filenames, `pack.json` and `arena.txt`. The latter is the editor's existing ISA1/ISA1z code. The reader checks up to 32 subscriptions, 512 KiB per pack, 8 KiB per arena and 4 MiB total per list. Invalid or unfinished entries are skipped. A failed content upload can retry its new item in the same process. A successful upload creates a private draft. Publishing permissions, live two-account subscriptions, item updates in Steam and the Deck badge require owner testing.
- **Daily results** offer a dated 1280×720 PNG containing score, stage, kills, time and loadout. The starting challenge date survives a midnight finish. **Highlights** prepare bounded WebM clips serially on the gallery/result screens when native file sharing is available. A single press calls the share sheet with a ready file while the gesture is active. Cancellation is silent. Unsupported native sharing uses the local save path. No uploads go to a public service automatically.
- **Replay-checked score boards** use `GET/POST /replay-scores`, with a D1 table separate from historical `/scores`. Actual host/solo game state supplies the initial sample, one sample per 15 seconds, and a final sample. The chain includes the existing replay simulation hash, run and scoring clocks, stage, score, kills, position and HP. A Worker checks links, cadence, bounded integers, day/week seed, plausibility, gauntlet score and the exact submitted result (time to milliseconds). A SHA-256 receipt and transactional top-100 insertion prevent duplicate scores and lost concurrent finishes. A GET returns 20. The existing world-goal receipt counts an accepted finish once. Only the canonical hero ID is stored as the public name.
- Board writes have a 512 KiB body limit, an existing per-isolate burst limit, and a best-effort 60-second KV cooldown keyed by a digest of the connecting address. The Worker discards the sample tape. A modified client can generate a consistent fabricated chain. The Worker does not independently simulate combat. A promoted host without the beginning of the recording, an assisted run, a custom arena or an enabled mod pack cannot populate this board. Local gameplay and scores are available offline.
- The owner checklist covers the Steam app and depots, native Deck review, Workshop, store, demo, Next Fest, Discord, codesigning, online migrations and release promotion. [Launch checklist](../../docs/LAUNCH.md)

## Release gates

- The installed Node version was 22.23.3. `npm run typecheck`, `npx vite build`, `npm test -- g10launch`, native CJS syntax checks and `git diff --check` passed. The visual and share tests ran against the local app. The final one-press files were a 142,968-byte 1280×720 PNG and a 241,090-byte WebM. Both stayed in the local test harness.
- Gate 2 baseline, Normal seeds 1–20: 15/20 loop clears (75%), stage clears 100/100/100/75%, median stage 4, mean 1,016.1 game seconds, no incomplete runs. The baseline already exceeded the 40–60% target. The lane leaves enemy tuning, weapons and permanent stats alone. The post-change run on the same 20 seeds reproduced every gameplay field for every seed, including the 75% loop clear rate and 1,016.1 s mean. Only CPU timings varied. Raw reports: `shots/g10-launch-skill-{before,after}.json`.
- Performance is an open release gate. macOS denied the standalone headless Chromium process at launch both before and after. A managed hardware Metal browser ran the stock scene measurements and budget checker. At high quality, 1280×720, the matched heavy scene initially measured median/p95 frame intervals of 16.7/16.8 ms (300 intervals in five seconds), and the post-change sample measured 16.7/33.3 ms (274 intervals). An independent post-change matrix sample of the same scene measured 58.0 fps, 16.7/16.8 ms, median 268 enemies and 499 projectiles. Low and medium measured 60.0 fps in this scene. Repeating the failed high-quality row later gave 35.9 fps, median/p95 intervals 16.7/33.3 ms and a longest frame of 1.65 s. The exact row is in `shots/g10-launch-bench-high-retry.json`. The shared machine's load average exceeded 100 during testing.
- The managed matrix produced all 60 normal rows and both renderer stress rows. The repository's checker rejected 51/62 scene rows on at least one budget. All four cold loads passed the stock checker. Slow 4G initially missed a shader transfer and passed on independent retries: title ready in 30.47 s (1,638,459 bytes) and fight ready in 25.60 s (1,662,281 bytes). Raw rows: `shots/g10-launch-bench.json`. A quiet machine must pass the stock timing gate before release.
- Standalone `npm run coop -- --offline` could not launch Chromium. Managed headless WebRTC completed restart, kick, disconnect and rejoin. The first pass captured 2,357 snapshots (mean 1,699 bytes, maximum 14,779; zero over 16 KiB) and missed the boss-intro client UID and ping portrait checks. One retry hit the 300-second browser tool deadline. Resuming the unchanged assertions across managed-browser calls let the default 80-second scenario finish with a pass (2,427 snapshots, mean 1,740 bytes, max 7,445). The busy host ran fewer timed events before its wall-clock cutoff, so a separate run explicitly executed both missed assertions: boss UID 253 on both peers and the ping portrait present on both. That run passed with 1,660 snapshots, max 7,120 bytes. Optional co-op screenshots were disabled on those retries.
- The managed Workshop UI test enabled an installed Mint Circuit pack, browsed the Workshop, selected the Sunny Plaza subscription from Collection → Arena Editor and submitted both private draft payloads through the native bridge fixture (1,458 and 248 characters). The native adapter tests exercise disk handling separately. Live Steam ownership, subscription delivery, Workshop visibility and physical Deck verification remain owner checks.
- `npm run balance` hit the standalone browser restriction. All four kits reached stage 3 using the stock invincible replay in managed Chromium. The saved fixture misses match the prior Gate 8 baseline exactly: Buster stage-two kills 9,700 vs 15,414, Laser stage-one ranks 8 vs 12, Rail kills 4,103 vs 5,677 and 10,622 vs 15,298. Scatter stayed within tolerance. [Prior balance measurement](g8-bossmaker.md)
- `npm test` passed all 157 files in the clean three-job run. The earlier four-job run passed 156/157 after retries. Under load, the Node host-migration fixture reached its real PeerJS constructor. Both the untouched source and the lane then passed that fixture in isolation; the clean full run required no retry. `npm run smoke` passed all whole-game checks, including the mortal run and game-over history. No test threshold, baseline or combat tuning was edited.

Clean 1280×720 high/heavy measured 60.0 fps, median/p95 frame intervals 16.7/16.7 ms, median 280 enemies and 499 projectiles (the pre-change median/p95 was 16.7/16.8 ms).
